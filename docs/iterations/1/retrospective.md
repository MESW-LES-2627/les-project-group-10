# Retrospective — Iteration 1

In this iteration, we focused on our CI pipeline and testing to improve code quality. Feedback from iter-0 was that we needed to focus on these areas. Since we had already completed several user stories in the previous iteration, we decided to implement only one user story this time.

We added our [Definition of Done](https://github.com/MESW-LES-2627/les-project-group-10/pull/13) as a permanent documentation file and added [issue templates](https://github.com/MESW-LES-2627/les-project-group-10/pull/15) and a [PR template and CI pipeline](https://github.com/MESW-LES-2627/les-project-group-10/pull/19). We added [unit tests for the backend and frontend](https://github.com/MESW-LES-2627/les-project-group-10/pull/40), [component tests for the frontend](https://github.com/MESW-LES-2627/les-project-group-10/pull/42), and [test execution in the PR pipeline](https://github.com/MESW-LES-2627/les-project-group-10/pull/41). We also spent a lot of time on deployment and our [continuous deployment pipeline](https://github.com/MESW-LES-2627/les-project-group-10/pull/43), which is ready for review.

The user story we implemented was [mentor profile editing](https://github.com/MESW-LES-2627/les-project-group-10/pull/44). Mentors can now update their public information after registering. We checked the flow with manual acceptance tests and automated tests.
